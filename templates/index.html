World Cup 2026 — Shooting Efficiency

PRT581 Group Project · Task 3 · Mildred

1Get the data

Downloads all 104 matches from FIFA's official data service and counts up what each team did, then saves the result to data/fifawcextract.csv, replacing whatever was in that file before.

Takes about half a minute — it downloads every match one at a time. There is no backup file, so a failed download gives an error rather than old data.
The fifa.com pages build their tables with JavaScript, so there is no table to read off the page itself; a fifa.com address is sent to FIFA's data service, which holds the same numbers. Any other address is read as a normal HTML table, and the table number picks which one. FBRef blocks automated downloads (403).

2Run the analysis

Does the wrangling and sampling, then the descriptive statistics, a 95% confidence interval and a two-sample t-test.
